# 패키지 설명서 (콘솔 상세 탭의 1층 "읽기") — 설계

2026-08-26

## 왜

콘솔 상세와 스튜디오는 같은 패키지를 각각 보여준다 — 하나는 설치본, 하나는 draft. 둘 다 매니페스트
어휘(`agents` · `scripts` · `services` · `edges` · `triggers` · `harness`)를 그대로 노출해서 비개발자는
"이 패키지가 뭘 해주는지"를 어느 화면에서도 읽지 못한다. 빌더 에이전트의 페르소나는 이미
"시스템 내부 이름을 답에 쓰지 마라 · 효용으로 설명하라"를 규칙으로 갖고 있는데, 화면이 그 규칙을 어긴다.

장기 방향은 두 화면을 **패키지 화면 하나**로 합치고 깊이를 세 층으로 두는 것이다:
읽기(사람 말) → 고치기(제자리 펼침 폼) → 파일(에디터). 이 문서는 그중 **1층만** 다룬다.

## 범위

- 콘솔 패키지 창(`PkgPane`)의 **상세 탭**을 설명서로 교체한다.
- 줄을 누르면 스튜디오의 해당 섹션으로 이동한다 (2층 펼침 폼은 다음 라운드).
- 그래프 옆 `Detail.tsx`(설정 면)는 손대지 않는다.
- 하단 액션(스튜디오에서 편집 · 데이터 폴더 열기 · 제거)은 그대로 둔다.

## 형식 — 질문-답 목록

왼쪽에 질문, 오른쪽에 답. 코드·영어 항목명·경로는 본문에 쓰지 않는다 (경로는 회색 보조 텍스트로만).

| 줄 | 재료 | 비었을 때 |
|---|---|---|
| 머리 | `icon` · `display_name` · `description` | — |
| 시킬 수 있는 일 | `scripts.source` 아래 `*.ts` 의 이름 (칩) | 아직 없음 |
| 스스로 움직이는 때 | `triggers[]` — cron 은 사람 말로 번역, event 는 "○○이 생기면" | 아직 없음 — 부르면 움직입니다 |
| 손대는 폴더 | workspace + `services[].dir` (이름, 회색 경로) | — (workspace 는 항상 있다) |
| 대화하는 곳 | 착지 에이전트가 있으면 "이 화면" + `surfaces.channels[].name` | 대화 없음 |
| 바깥 연결 | `services[]` 의 url/api 형 (이름) + 이 패키지가 consumer 인 edges ("○○ 의 도구를 빌려 씀") | 아직 없음 |
| 동작 엔진 | 활성 harness variant 의 `llm.provider` 를 표시명으로 | 하네스 없음이면 줄 생략 |
| 필요한 것 | `requires.binaries[].name` | 줄 생략 |

### cron 번역 규칙

`m h * * *` → "매일 h시 m분" (m=0 이면 분 생략, 12 이상은 "오후"), `m h * * 1-5` → "평일 h시",
`m h * * d` → "매주 ○요일 h시", `*/n * * * *` → "n분마다", `0 */n * * *` → "n시간마다".
그 밖의 표현은 **원문을 그대로** 보여준다 — 짐작하지 않는다(`Preview.tsx` TimePane 과 같은 규칙).
`tz` 가 있으면 뒤에 회색으로 붙인다.

### 수정 중 표시

콘솔은 설치본을 보여준다. `draft-list` 에 이 패키지의 draft 가 있고 변경이 있으면 머리 옆에
"수정 중 · 아직 적용 안 됨 n건" 칩. 누르면 스튜디오. 본문을 draft 로 바꿔 보이지 않는다 —
"콘솔에서 보이는 것 = 지금 돌아가는 것"을 지킨다.

## 구조

- `lib/describe.ts` — `describe(manifest, ctx) → Row[]`. 순수 함수. `ctx` 는 workspace · edges ·
  활성 harness 이름 · 파일 목록처럼 매니페스트 밖에서 오는 값. `cronToKorean(expr) → string | null`
  도 여기(번역 못 하면 null).
- `components/Describe.tsx` — `Row[]` 를 그린다. 각 줄의 `sec` 로 `/studio/?pkg=&sec=` 링크.
- `PkgPane.tsx` 의 `DetailFace` 본문을 `Describe` 로 교체. 하단 액션·제거 확인은 남긴다.
- 스타일은 `globals.css` 의 기존 `.rc-*` 토큰 위에 `.ds-*` 몇 개.

## 테스트

`lib/describe.test.ts` (node:test): cron 번역 표 · 빈 매니페스트 → 빈 줄 문구 · 시스템 패키지
`relay.yaml` 을 넣었을 때 줄 수와 각 줄의 답. 화면은 `npm run relay -- build system` 후 눈으로 확인.
